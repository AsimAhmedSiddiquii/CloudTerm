# Security policy

## Reporting a vulnerability

Please do not disclose security-sensitive issues in a public GitHub issue.
Report them through the repository's GitHub Security Advisory form when it is
available. If private advisories are unavailable, contact the repository
maintainer privately through the contact information on the maintainer's
GitHub profile and include:

- the affected CloudTerm version or commit;
- the operating system and installation method;
- clear reproduction steps; and
- the potential impact.

Please avoid including private keys, vault passwords, host credentials, or
other sensitive connection data in a report.

## Supported versions

The latest published release is the primary supported version. Security fixes
may be backported to an older version when the issue is practical to fix
without changing its connection or vault format.
